# To check if a service is healthy 
1> systemctl is-enabled <service_name> (to see if a service is started/running or not)
2> journalctl -u <service_name> ( to see the logs of a service)
3> systemctl status <service_name>

# To change ownership and permission 
 of a file named file.txt

 2> sudo chmod 764 file.txt
