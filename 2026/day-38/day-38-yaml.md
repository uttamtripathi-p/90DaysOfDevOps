# Two ways to write a list in yml

##  Block Style (multi-line)
### Each item on its own line
### Starts with a dash - and a space
### More readable, preferred for longer lists

## Inline / Flow Style
### All items in a single line inside [ ]
### Separated by commas
### More compact, preferred for short lists


# When would you use | vs >?
## | will be used when want to run different commands in diff. lines
## > will be used when having user script or summary.
